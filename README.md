# Alvaro Cruz Perez - Biomedical Engineering Portfolio

This repository is a general engineering portfolio for GitHub Pages. It is intentionally broad rather than tailored to one employer.

## Current structure

- `index.html` - homepage, selected projects, research overview, publications/presentations, and about section
- `projects/cradle.html` - MRI-compatible ferret cradle case study
- `projects/macro.html` - NDA-safe MACRO capstone case study
- `projects/gait.html` - markerless ferret gait-analysis case study
- `projects/bioboat.html` - BioBoat biohybrid robotics / bioprinting case study
- `projects/wearable.html` - Track Your Trek heat-illness wearable case study
- `projects/handover.html` - Hand Over Design Competition robotics/programming case study
- `research/` - public research posters and presentation files linked from the site
- `project-docs/` - supporting coursework project reports/presentations linked from case studies
- `resume/Alvaro_Cruz_Perez_Resume.pdf` - current general resume
- `assets/images/` - optimized public visuals used by the site
- `assets/styles.css` - site styling

## Portfolio positioning

The site emphasizes a multidisciplinary biomedical-engineering profile built around:

1. Mechanical design and rapid prototyping
2. Electromechanical system integration
3. Medical-device and research-instrument development
4. Biomechanics, computer vision, and quantitative analysis
5. Biofabrication and tissue-engineered systems
6. Validation, troubleshooting, and cross-functional collaboration

## Confidentiality

The MACRO capstone is represented only at a high level because it is NDA-restricted. Do not add protected images, schematics, test data, sponsor materials, or design files unless they are explicitly cleared for public release.

For active research, only public conference material is embedded. Keep unpublished animal data, raw videos, internal lab setups, and non-public technical information off the public site unless approved by the lab.

## Publish with GitHub Pages

Create or use the repository:

`alvarocruz15.github.io`

Upload the contents of this folder to the repository root so `index.html` is at the top level.

Then open GitHub repository **Settings > Pages** and choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

The site will be available at:

`https://alvarocruz15.github.io`

## Updating later

Keep the portfolio itself relatively stable. Tailor the resume and cover letter for individual applications, while using this website as the deeper technical story behind those documents.
